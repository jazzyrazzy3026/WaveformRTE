# WaveformRTE

WaveformRTE — an effects-first web synth built from scratch (no Beepbox code).

Getting started

1. Install dependencies:

   npm install

2. Start dev server:

   npm run dev

Overview

- TypeScript + React + Vite
- Small audio engine using the Web Audio API and an AudioWorklet bitcrusher
- Effects included: bitcrusher, delay (with feedback), 3-band EQ

This scaffold is intentionally minimal. Extend effects, add presets, UI polish, and MIDI input as needed.
